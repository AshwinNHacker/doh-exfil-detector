# Contributing

Contributions are welcome — detection rules, resolver database entries,
false-positive reports from real-world use, and documentation improvements
are all useful.

## Setup

```bash
git clone https://github.com/AshwinNHacker/doh-exfil-detector.git
cd doh-exfil-detector
pip install -e ".[dev]"
pytest -v
```

## Guidelines

- **New detection rules** go in `scoring.py`. Each rule should:
  - Be independently testable (add a case to `tests/test_scoring.py`).
  - Contribute a capped point value proportional to how strong a signal it
    is in isolation.
  - Ship with a `detail` string explaining *why* it fired in plain
    language — no rule should be a black box to the analyst reading a
    report.
  - Be documented in `docs/DETECTION_METHODOLOGY.md`, including its known
    false-positive sources.
- **New resolver entries** go in `data/known_doh_resolvers.json`. Please
  use only publicly documented DoH endpoints (provider's own
  documentation/support pages) and cite the source in your PR description.
- **No real captured traffic** in the repository, ever — `examples/` uses
  only synthetic pcaps generated by `scripts/generate_sample_pcap.py`.
  If you're adding a new example scenario, extend that generator rather
  than committing a real capture.
- Run `pytest -v --cov=doh_detector --cov-report=term-missing` before
  opening a PR and try to keep coverage from regressing.
- This project performs no TLS decryption anywhere. PRs that would require
  access to TLS key material or application-layer plaintext will not be
  accepted — see `docs/ARCHITECTURE.md` for the reasoning.

## Reporting false positives / false negatives

Please open an issue with (if possible):
- The specific rule(s) that fired (or should have fired).
- The relevant `FlowFeatures` values (`doh-detector analyze --format json`
  includes the full feature vector per flow) — redact source/destination
  IPs if needed.
- What the traffic actually was (browser DoH, VPN client, enterprise
  resolver, etc.).

This kind of feedback is exactly what tunes the default thresholds over
time.
